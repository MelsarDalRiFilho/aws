## Dois pontos para você decidir

1. **O cache DynamoDB fica um pouco redundante.** O cadastro também vai ficar no DynamoDB, então guardar uma cópia em outra tabela DynamoDB quase não reduz a latência. Há duas opções mais simples:
   - **Ler direto do cadastro.** Recomendo esta.
   - **Cache em memória na própria Lambda**, que é gratuito e fica guardado entre invocações.

   O cache só vale a pena se o cadastro passar a vir de uma fonte lenta ou externa no futuro.
2. **A API Key não autentica o dispositivo.** Ela serve para controlar uso e cota, e dá para extraí-la do app. Para o POC está bom. Em produção, vale adicionar uma assinatura HMAC por dispositivo ou usar o Cognito.
